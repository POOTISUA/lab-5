# Лабораторна робота №5
## Проєктування потокобезпечної структури даних (Варіант 24)

- **Варіант:** 24
- **Структура даних:** **С4** — обмежена пріоритетна черга місткістю `256` (max-heap у масиві)
- **Кількість потоків:** `n = 6` (`n_w = 3` потоки запису з непарними номерами `1, 3, 5`; `n_r = 3` потоки читання з парними номерами `2, 4, 6`)
- **Операції запису:** `push(p, x)` і `pop()` по черзі в тому самому потоці
- **Операції читання:** `peek_max()` і `size()` порівну (`50 / 50`)
- **Режими синхронізації:**
  1. Глобальний замок (`threading.Lock`)
  2. Замок читання-запису (`WriterPreferringRWLock` на базі `threading.Condition`)
